Privacy-first document handling

Seolapin does not operate a document-processing server. Document parsing, preview rendering, draft editing, and export are handled on device.

Release builds include Google AdMob and Google User Messaging Platform SDKs for banner ads and ad privacy choices. Document body text is not passed into ad request data.

HWP/HWPX Notice

Seolapin is independently developed based on publicly available HWP file format information and HWPX/OWPML document format information.

The HWP/HWPX document processing features are implemented directly in Swift without using the Hancom SDK, Hancom Office components, Hancom executables, Hancom converters, or external HWP/HWPX-specific libraries.

Seolapin is not affiliated with, endorsed by, certified by, or sponsored by Hancom Inc.
